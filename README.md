\# 🎓 EduRisk



\## Student Performance \& Academic Risk Predictor



EduRisk is a machine learning-based web application that predicts a student's expected final marks and identifies their academic risk level based on study and academic factors.



\## 🎯 Problem Statement



Students may not know early enough when their academic performance is declining.



EduRisk uses student-related academic and study information to provide an estimated performance score, an academic risk level, and a simple recommendation.



\## 💡 Features



\- 📚 Study hours analysis

\- 🏫 Attendance consideration

\- 📊 Previous marks consideration

\- 📝 Assignment score consideration

\- 😴 Sleep hours consideration

\- 🤖 Machine learning prediction

\- ⚠️ Academic risk classification

\- 💡 Improvement recommendations

\- 🌐 Streamlit web interface

\- ☁️ AWS SAM/Lambda local integration
